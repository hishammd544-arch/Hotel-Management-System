# Hotel Management System

## Run the project

1. Extract the ZIP.
2. Open this entire folder in Visual Studio Code.
3. Install the **Live Server** extension.
4. Open `login.html`, right-click, and select **Open with Live Server**.
5. Use the demo login details in `START_HERE.txt`.

## Team responsibility

- **Person 1 – Admin:** `Admin.html`, `Room.html`, `Staff.html`, `Sales.html`, `Complaints.html`, `Maintenance.html`, `Reviews.html`, `css/Admin.css`, and related files in `js/`.
- **Person 2 – Receptionist:** receptionist dashboard and pages, `js_receptionist/`, `css_receptionist/`, and `images_receptionist/`.
- **Person 3 – Room Service:** room service pages, `JavaScript/`, `css_room_service/`, and `images_room_service/`.
- **Person 4 – Customer:** customer pages, `customer_JS/`, `css_customer/`, and `image/`.

Keep the existing folder structure so relative links continue to work. See `START_HERE.txt` for demo credentials and more detail.

## Scope

This is the supplied HTML/CSS/JavaScript front-end project. It does not include an ASP.NET/C# backend or database implementation. Some original features may need further integration and testing.


## Important technical note
This is a front-end classroom demo built with HTML, CSS, and JavaScript. Sign-up accounts are stored in the browser's localStorage for demonstration only. It does not include a C#/.NET server or a real database, so it is not suitable for real user accounts or production use.
